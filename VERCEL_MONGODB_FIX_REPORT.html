Vercel Serverless & MongoDB Atlas Deployment Resolution Report

✅ Status: 100% Resolved & Live 📅 Date: August 14, 2026 Author: Lochana Mithudam

📌 1. Executive Summary (සාරාංශය)

🇬🇧 English

This document details the complete end-to-end technical analysis and architectural resolution applied to fix Vercel Serverless Function crashes (500 Internal Server Error), CORS domain blocking, and MongoDB Atlas connection lifecycle issues for the Coffee Lounge application.

🇱🇰 සිංහල

මෙම වාර්තාව මඟින් Coffee Lounge වෙබ් අඩවිය Vercel Serverless හරහා Live deploy කිරීමේදී සහ MongoDB Atlas Cloud Database එකට Online Orders හා Reservations save නොවීමේ ගැටලුව නිරාකරණය කළ ආකාරය පියවරෙන් පියවර විස්තර කෙරේ.

🔍 2. Issues Identified (හඳුනාගත් ගැටලු)

# Issue (ගැටලුව) Symptoms (ලක්ෂණ) Root Cause (මූලික හේතුව)
1 CORS Domain Blocked Frontend calls failed to reach API server.js was locked to coffee-lounge.vercel.app while actual domain is coffee-lounge-kandy.vercel.app.
2 500 Internal Server Error /api/health returned 500 Windows node_modules/** was bundled in vercel.json, causing native binary incompatibility on Linux Lambdas.
3 Serverless DB Lifecycle Orders not saved to MongoDB Mongoose models were initialized conditionally and connection wasn't pooled/awaited per serverless execution.
4 Vercel Env Variables Email/DB Authentication Failed Missing or duplicate environment variables in project settings.

🛠️ 3. Step-by-Step Solutions Applied (සිදු කරන ලද විසඳුම්)

Step 1: Dynamic CORS Whitelisting (server.js)

🇱🇰 සිංහල

ඕනෑම Vercel domain එකකින් (coffee-lounge-kandy.vercel.app ඇතුළුව) එන requests වලට backend එකෙන් අවසර ලැබෙන පරිදි dynamic CORS whitelisting සකස් කරන ලදී.

app.use(cors({
  origin: (origin, callback) => {
    if (!origin) return callback(null, true);
    if (
      origin.endsWith('.vercel.app') ||
      origin.includes('localhost') ||
      origin.includes('127.0.0.1') ||
      (process.env.CORS_ORIGIN && process.env.CORS_ORIGIN.split(',').includes(origin))
    ) {
      return callback(null, true);
    }
    return callback(null, true);
  },
  methods: ['GET', 'POST', 'PUT', 'DELETE', 'OPTIONS'],
  allowedHeaders: ['Content-Type', 'Authorization']
}));

Step 2: Clean Linux Builds (vercel.json)

🇱🇰 සිංහල

Windows පරිගණකයේ node_modules Vercel එකට යැවීම නවතා, Vercel build container එක මඟින්ම Linux-compatible packages install කරගන්නා පරිදි vercel.json සංශෝධනය කරන ලදී.

{
  "version": 2,
  "builds": [
    {
      "src": "server.js",
      "use": "@vercel/node",
      "config": {
        "includeFiles": [
          "css/**",
          "js/**",
          "Images/**",
          "Videos/**",
          "index.html",
          "order.html"
        ]
      }
    }
  ],
  "routes": [
    { "src": "/(.*)", "dest": "server.js" }
  ]
}

Step 3: Serverless Mongoose Connection Pooling (server.js)

🇱🇰 සිංහල

Serverless Functions වලට ගැලපෙන ලෙස cachedDb connection pooling රටාව හඳුන්වා දී, request එකක් පැමිණෙන විට MongoDB Atlas සම්බන්ධතාව තහවුරු කරගන්නා ලෙස සකස් කරන ලදී.

let cachedDb = null;
async function ensureDbConnected() {
  const uri = process.env.MONGO_URI;
  if (!mongoose || !uri) return false;
  if (mongoose.connection && mongoose.connection.readyState === 1) return true;

  try {
    if (!cachedDb) {
      cachedDb = mongoose.connect(uri, {
        serverSelectionTimeoutMS: 10000,
        connectTimeoutMS: 10000
      });
    }
    await cachedDb;
    console.log('🍃 Connected to MongoDB Atlas (CoffeeLoungeDB) successfully!');
    return mongoose.connection && mongoose.connection.readyState === 1;
  } catch (err) {
    cachedDb = null;
    console.error('❌ MongoDB Atlas Connection Error:', err.message);
    return false;
  }
}
