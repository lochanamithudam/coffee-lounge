3. Backend Modules & Storage Reference

Component File Path Functionality
Server Engine server.js Express.js server, route definitions, dynamic port fallback (5000 ➔ 5001).
Environment Config .env Holds EMAIL_USER and Gmail App Password EMAIL_PASS securely.
Reservations Database data/reservations.json Stores array of table bookings with reference IDs and guest preferences.
Orders Database data/orders.json Stores online food/beverage purchases, itemized breakdown, tax, and fees.
VIP Subscribers data/subscribers.json Stores newsletter subscriber list with deduplication logic.
Mailer Service Nodemailer Asynchronous Gmail SMTP engine with fallback logging on failure.
